# 核心实体清单

## 目标

用于约束首版教培平台的核心数据模型，避免业务范围膨胀。

## 系统与权限

- `sys_user`
- `sys_role`
- `sys_menu`
- `sys_user_role`
- `sys_role_menu`
- `sys_dict_type`
- `sys_dict_data`
- `sys_operation_log`

## 组织

- `jp_org`
- `jp_campus`
- `jp_classroom`
- `jp_term`
- `jp_time_slot`

## 员工与教师

- `jp_employee`
- `jp_teacher`
- `jp_teacher_campus`
- `jp_teacher_course`

## 学员与家长

- `jp_student`
- `jp_student_parent`
- `jp_student_tag`
- `jp_student_tag_rel`

## 教学

- `jp_course_category`
- `jp_course`
- `jp_class_type`
- `jp_class`
- `jp_class_teacher`
- `jp_class_student`

## 排课与执行

- `jp_schedule_plan`
- `jp_lesson`
- `jp_lesson_attendance`
- `jp_leave_record`
- `jp_makeup_record`
- `jp_transfer_record`
- `jp_suspend_record`

以下业务表建议统一预留：

- `id`
- `org_id`
- `campus_id`
- `created_by`
- `updated_by`
- `created_time`
- `updated_time`
- `deleted`
