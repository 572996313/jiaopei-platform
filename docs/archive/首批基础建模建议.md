# 首批基础建模建议

> 状态：**已归档（历史过程方案，不再维护，2026-09-20）**。建模建议已被实际落地取代，现行表清单见 `docs/核心实体清单.md`，schema 事实以 Flyway 迁移（`backend/app/src/main/resources/db/migration/`）为准。

## 1. 范围与原则

首批核心实体仅包含：

- `institution` 机构
- `campus` 校区
- `classroom` 教室
- `term` 学期
- `time_slot` 时间段

建模原则：

- 主键统一使用 `bigint`
- 所有业务表保留审计字段
- 状态字段统一使用业务 `status`
- 首版优先支持线下班课教务主链路，不提前引入收费、库存、ERP 逻辑

统一审计字段建议：

- `created_at`
- `created_by`
- `updated_at`
- `updated_by`
- `deleted`

## 2. 实体建议

## 2.1 institution

用途：

- 表示教培平台中的机构主体

建议字段：

- `id`：主键
- `org_code`：机构编码
- `org_name`：机构名称
- `short_name`：机构简称，可空
- `contact_name`：联系人，可空
- `contact_phone`：联系电话，可空
- `province_code`：省编码，可空
- `city_code`：市编码，可空
- `district_code`：区县编码，可空
- `address`：总部地址，可空
- `timezone`：时区，默认 `Asia/Shanghai`
- `status`：`draft / active / suspended / closed`
- `opened_at`：开业日期，可空
- `remark`：备注，可空

唯一约束建议：

- `unique(org_code)`

说明：

- 机构名称不建议强制全局唯一

扩展点：

- 品牌体系
- 法人主体
- 学段配置
- 课程体系

## 2.2 campus

用途：

- 表示机构下的具体校区

建议字段：

- `id`：主键
- `institution_id`：所属机构 ID
- `campus_code`：校区编码
- `campus_name`：校区名称
- `campus_type`：`direct / franchise / managed`
- `phone`：联系电话，可空
- `principal_name`：负责人，可空
- `province_code`：省编码
- `city_code`：市编码
- `district_code`：区县编码
- `address`：详细地址
- `capacity_limit`：理论最大容纳人数，可空
- `status`：`planning / active / suspended / closed`
- `opened_at`：启用日期，可空
- `sort_no`：排序值，可空
- `remark`：备注，可空

唯一约束建议：

- `unique(institution_id, campus_code)`
- `unique(institution_id, campus_name)`

说明：

- 校区名称建议在机构内唯一，不做全局唯一

扩展点：

- 营业时间
- 排课策略
- 可开班学段

## 2.3 classroom

用途：

- 表示校区内可排课的教室资源

建议字段：

- `id`：主键
- `campus_id`：所属校区 ID
- `classroom_code`：教室编码
- `classroom_name`：教室名称/编号
- `room_type`：`normal / computer / lab / multi_function`
- `floor_no`：楼层，可空
- `seat_capacity`：座位数
- `area_sqm`：面积，可空
- `equipment_tags`：设备标签，建议 `json/text`
- `status`：`idle / active / maintenance / disabled`
- `allow_scheduling`：是否允许排课
- `remark`：备注，可空

唯一约束建议：

- `unique(campus_id, classroom_code)`
- `unique(campus_id, classroom_name)`

说明：

- 教室只挂校区，不直接挂机构

扩展点：

- 座位图
- 教室设备明细
- 不可用规则

## 2.4 term

用途：

- 表示教学学期或办学周期

建议字段：

- `id`：主键
- `institution_id`：所属机构 ID
- `term_code`：学期编码，如 `2025SPRING`
- `term_name`：学期名称，如 `2025春季`
- `academic_year`：学年，如 `2025`
- `season`：`spring / summer / autumn / winter`
- `start_date`：开始日期
- `end_date`：结束日期
- `enrollment_start_date`：招生开始日期，可空
- `enrollment_end_date`：招生结束日期，可空
- `status`：`draft / active / ended / archived`
- `is_default`：是否默认学期
- `remark`：备注，可空

唯一约束建议：

- `unique(institution_id, term_code)`

校验建议：

- `start_date <= end_date`
- 同机构默认学期同时只能有一个

说明：

- 首版 `term` 先挂机构，不直接挂校区

扩展点：

- 节假日模板
- 学期分段
- 学费策略

## 2.5 time_slot

用途：

- 表示可复用的上课时间段模板，不绑定具体日期

建议字段：

- `id`：主键
- `institution_id`：所属机构 ID
- `campus_id`：所属校区 ID，可空
- `slot_code`：时间段编码
- `slot_name`：时间段名称
- `weekday`：`1-7`
- `start_time`：开始时间
- `end_time`：结束时间
- `duration_minutes`：时长
- `slot_type`：`teaching / self_study / exam / break`
- `applicable_scene`：`regular / holiday / intensive`
- `status`：`active / inactive`
- `sort_no`：排序值
- `remark`：备注，可空

唯一约束建议：

- 机构级模板：`unique(institution_id, slot_code)`
- 校区级模板：`unique(campus_id, slot_code)`
- 可选补充：`unique(institution_id, campus_id, slot_name)`

校验建议：

- `start_time < end_time`
- `duration_minutes > 0`

说明：

- `campus_id` 为空表示机构公共模板
- `campus_id` 非空表示校区私有模板

扩展点：

- 双周/单周
- 跨天时段
- 节次序号
- 特殊日程模板

## 3. 主外键关系

- `institution 1 - n campus`
- `campus 1 - n classroom`
- `institution 1 - n term`
- `institution 1 - n time_slot`
- `campus 0..1 - n time_slot`

实现建议：

- `campus.institution_id -> institution.id`
- `classroom.campus_id -> campus.id`
- `term.institution_id -> institution.id`
- `time_slot.institution_id -> institution.id`
- `time_slot.campus_id -> campus.id`

## 4. 核心业务规则

- 教室必须属于某个校区
- 校区必须属于某个机构
- 如果 `time_slot.campus_id` 非空，则其校区必须属于相同 `institution_id`
- `classroom.status = maintenance / disabled` 时，后续排课模块禁止分配
- `campus.status = closed` 或 `institution.status = closed` 时，下游开班与排课应整体禁用

## 5. 状态枚举建议

- `institution.status`：`draft, active, suspended, closed`
- `campus.status`：`planning, active, suspended, closed`
- `classroom.status`：`idle, active, maintenance, disabled`
- `term.status`：`draft, active, ended, archived`
- `time_slot.status`：`active, inactive`

建议：

- 首版可直接用 `varchar` 存储
- 暂不拆成独立字典表

## 7. 首批落库取舍

- `term` 先挂机构，不挂校区
- `time_slot` 只做模板，不绑日期
- `classroom` 只存资源属性，不拆设备子表
- 所有业务实体保留 `code` 字段，方便导入和人工沟通
