# 前端页面开发手册（执行细则与反模式对照）

> **定位**：本手册不新增约定，只把 [AGENTS.md](../AGENTS.md) 前端章节的口径落成**动手时的落点表、骨架代码与反模式对照**。冲突一律以 AGENTS.md 为准；这里说的是"该写在哪一行、照着哪个页面抄"。
>
> **为什么值得逐条守住**：全站页面正在向"配置即可生成统一形态"收敛（`sys_list_config` + `page_json`/`dialog_json`/`actions_json`，契约见 [config-contract.md](config-contract.md)）。手写页每偏离一次落点，将来就多一个要用特例代码抹平的口子。**判据不是"这样挺好看"，而是"配置化引擎能不能长出这一维"**。
>
> 最后更新：2026-09-28（对应当时的全站量高复测与 V87 拆页）。

## 1. 一页的三层结构（恒等式，不多不少）

```
① .table-toolbar   按钮行：本页动作(左) │ 圆形刷新 │ 会跳走的按钮(右) │ 说明/范围回显(贴右端)
② FilterBar        筛选行：筛选控件(左) … 「查询」「重置」(固定行末)
③ .panel-card      表格：TableFillBox 吃满剩余高 → el-table → 分页
```

纵向预算（内容区 = `.app-content`，页签行以下）：**1440×900 = 729px（达标线）**，1366×768 = 597px（允许差一行，但保存按钮与它的上一行参数必须可见）。

**自测判据一句话**：鼠标进这一页，不碰滚轮能不能点到"保存 / 新增 / 提交"？不能就是要改，改动按 §5 的四级杠杆从上往下走。

外壳（横幅 64px + 页签行 28px + 各类边距内边距）已经把固定占位吃掉了，**往横幅或页签行里加东西可以，在它们下面再加一行不行**。

## 2. 落点表：这个元素该写在哪

| 元素 | 唯一落点 | 写法 | 参照 |
| --- | --- | --- | --- |
| 新增/编辑/删除/导入/导出/**打开弹窗**的入口 | 按钮行左半 | 主按钮 `type="primary"` 排最前 | `ClassroomManagementView.vue:8-16` |
| 圆形刷新（分隔位） | 按钮行中间 | `<el-button :icon="Refresh" circle @click="refreshAll" />`，**每页都要有** | 同上 `:10` |
| 会跳去别处的按钮（`router.push`） | 按钮行右半，圈圈之后 | 「分班与名册」「节次明细」「班型档案」 | `TimeSlotListView.vue:8-31` |
| 长口径说明 | 按钮行右端，`el-popover` 问号 | `<NoteHint label="口径" :width="520">` | `ScheduleCompletenessView.vue:8-32` |
| 动态范围回显（"当前机构：X"） | 按钮行右端 | `<div class="education-context-text">`，CSS 自带 `flex:1 + text-align:right` | `ClassroomManagementView.vue:11-15` |
| 筛选控件 | `FilterBar` 默认插槽 | **一个控件 = 一个顶层子节点** | `FilterBar.vue:38-40` |
| 「标题 + 控件」并排的筛选项 | 同上，但两者包进同一个 `<span class="filter-bar-group">` | 否则标题被多算一个控件、折叠点错位 | `FilterBar.vue:61-72` |
| 一句短句说明（整屏一颗按钮都没有时） | `FilterBar` 的 `#extra` | 只读表、脱敏提示这一类 | — |
| 多表同屏的卡内表头 | `.education-table-head` | 与 `.table-toolbar` 同规则：标题+按钮靠左成组、说明靠右 | `CourseManagementView.vue:58-80` |
| 行内操作 | 表格操作列，`fixed="right"` | `.table-actions` 包一层 | `ClassroomManagementView.vue:77-84` |
| 弹窗内错误提示 | dialog 顶部 | `el-alert.education-alert :closable="false"` | `ClassroomManagementView.vue:98-101` |

**按钮不许出现在行右端，也不许塞进筛选行的 `#extra`**——`#extra` 只留给"这一屏一颗按钮都没有"的说明。用户就是靠那颗圈圈判断"哪些按钮会把带走"。

## 3. 反模式对照表（主要用途：写完自查 / review 时对着挑）

症状都取"肉眼能看到的表现"，方便直接在缺陷单里复述。

### 3.1 纵向与布局

| 症状 | 根因 | 处置 | 参照 |
| --- | --- | --- | --- |
| 保存按钮要滚轮才点得到 | 一屏叠了多件事（C 型页） | 按**动作**拆页互跳，不是折叠（`el-collapse` 不算解决，展开照样逼出滚轮，已被退回过一次） | V82~V87 六次拆页 |
| 筛选栏挤成两行 | 档案下拉组件带了内联 `width:100%` | 宽度收在组件的 `.archive-select`（筛选栏 240px、弹窗表单仍 100%），**不许退回内联样式** | `styles/index.css:937-939` |
| 一行筛了七八个条件 | 混了两类筛选 | `FilterBar` 超 `collapseAt`(默认 4) 自动折叠；折了说明这屏该拆走一类 | `FilterBar.vue:72` |
| 卡片标题下又一行按钮、又一行说明 | 一行干了三件事 | 一屏每张卡最多 1 行标题 + 1 行动作；卡内表格主按钮并进 `.education-table-head` 右侧，说明并进页面按钮行右侧 | — |
| 什么都没选，页面已经空卡占掉大半屏 | 未选上游的区块无条件渲染 | 未选中时**整卡收成一行提示**，选中才铺开 | `/classes` 班级主档 |
| 三张卡各写一遍"当前机构：X" | 页面级信息被重复三遍 | 只在页面按钮行右侧写一次；卡头只留卡标题+卡内动作。纯回显不了数据的开关直接删 | V86 `/campus` |
| 页面总高随数据量涨到 1400~3600px | 列表/明细块没封顶 | 任何列表块必须有 `max-height`，内部自己滚；页面总高不许被数据顶开 | `/schedule` `/dashboard` |
| 两张并排卡装不进 729、或第三张卡整行铺开还撑高 | 用了 core 的 `.resource-grid`（末卡 `grid-column:1/-1` + 表体钉 398px 十行保底） | 页面自定 grid + `grid-template-rows:minmax(0,1fr)` | `/campus` 的 `.campus-grid` |
| 横向滚动条贴在最后一行下面，下面一片空白 | 给主列表传了 `height="100%"` | EP 把表体内联高算成 `bodyScrollHeight`，父链只有 `min-height` 时百分比解析为 auto → 表体塌成内容高。必须用 `TableFillBox` 自量成 **真实 px** 再传 | `TableFillBox.vue:7-19` |
| 同类并列卡竖排叠成一长条 | 没并排，也没换页 | 同类卡两列并排；跨类必须换页。**判据是"语义该不该同屏"，不是省了多少 px** | V85/V86/V87 |

### 3.2 表格

| 症状 | 处置 | 参照 |
| --- | --- | --- |
| 宽表读串行 / 滚到后面列不知道在看哪一行 | `border row-key="id" highlight-current-row` + 身份列 `fixed="left"`。**不加 `stripe`**——竖线已经把表切格，再叠斑马成小房间格纹；行节奏交给"悬停整行 + 当前行左边线" | `ClassroomManagementView.vue:33-40` |
| 人数、课时、金额这些数字看不出量级 | 量值列 `align="right"`（表头全站居中，对齐只作用于数据格）；**标识符不对齐**：id、手机号、编码保持左对齐，右对齐反而难逐字核对 | 同上 `:58-59` |
| 数字列有千分位/精度漂移 | 大 ID 走 `String(id)` 比较，见 §3.5 | `core/src/api/http.ts` |
| 点了表头没反应，且不报错 | 后端白名单缺这个键。判据：**该列只展示一个字段 ∩ 后端白名单里有这个键**，缺一就不加箭头。要加就扩后端白名单，**不搞页面特例** | `PageSortSupport.apply` |
| 弹窗重开后表头箭头消失了 | `destroy-on-close` 的弹窗每次重开表头都重建，`handleOpen()` 里必须 `sort.resetSort()` | `ScheduleRuleListDialog.vue:218-227` |
| 清完筛选排序箭头还在 | 常驻页传 `clearTableSort`，让清筛选按钮一并清掉排序状态 | `use-table-sort.ts` |
| 主键相同的行分页会重/漏 | 后端 `PageSortSupport` 主键兜底 tiebreaker，前端不要自己拼 ORDER BY | — |
| 树表/矩阵表想加排序 | **不加**。行序即层级/透视结构（菜单管理、权限总览、完成度动态周列） | — |
| 每页都加了一列勾选框 | 本仓库后端**没有任何批量写接口**，checkbox 属伪需求。出现真批量端点时再全站统一加 | — |

### 3.3 交互触发

| 症状 | 处置 |
| --- | --- |
| 选一个筛选条件就发一次请求，连点三下卡三次 | `@change`/`@clear` **一律不许绑查询**。只有「查询」按钮触发；输入框保留 `@keyup.enter` |
| 换了校区列表还是旧数据 | `resetFilters()` 清空本页控件后**立即生效**并保留分页 size |
| 下拉打开要等、输入中文一直发请求 | 按需搜索：300ms 防抖 + 打开时先给一屏（`visible-change`）+ `.last("LIMIT 30")` 封顶 |
| 日期前后翻页点了就查 | **允许的例外**：那是导航不是筛选条件（排课/执行页「前一天/下一周」） |
| 弹窗内小工具条、只读面板的年份切换也点了要再查一次 | **允许的例外**：没有"改完再决定"的语义 |

### 3.4 下拉与显示名

| 症状 | 根因 | 处置 |
| --- | --- | --- |
| 打开学员页卡数秒 | `el-select` 即便折叠也会把每个 `el-option` 渲染进 DOM（3583 个选项实测停 10 秒） | 服务端按需搜索：后端 `GET /xxx/options` 只回下拉与回显需要的字段（**别把监护人电话一类敏感字段带进载荷**），前端收进组件 |
| 下拉框收起后显示成裸 ID | 已选项不在当前这批搜索结果里 | 模块级 `Map` 缓存"见过的 id → 显示名"，查不到回显 `学员 #id`。**脏数据要可见，不硬猜、不写静态映射兜底**。不要把名称当 prop 一层层传（每个调用点都会漏） |
| 按 id 补取名成功后，下拉里仍显示裸 ID，点开一次才刷回来 | `el-option` 的 `:key` 只写了 id | `:key="`${item.id}-${item.label}`"` —— EP 只在选项实例**增减**时重算框内显示 |
| 表格行只有 id，名称显示不出来 | 不该为此改分页/报表 DTO 加冗余 `className` 列 | 给 options 接口加 `ids` 参数（上限 200、传了 ids 忽略 `keyword`），行加载后 `ensureClassLabels()` 补名 |
| `el-select` 显示成裸数字 | 小号 id（种子 `1`）运行期是 `Number`，生产是雪花 `String` | prop 声明 `string \| number`，拼参数 `String(...)`，`:value` 也写 `String(item.id)` |
| 表单默认值是个 `item_value` 字符串 | 预置进前端了 | **表单默认值一律留空**，要默认值由后端取库默认；条目被停用/删除时表单会提交无效值 |

### 3.5 数据与权限

| 症状 | 处置 |
| --- | --- |
| 深夜模式下某块是白底黑字以外的一团糊，或深字压深底 | 取色一律走语义令牌（`--card-bg`/`--text-*`/`--soft-*-bg`+`-ink` 成对），**业务页不许写死 `#fff`、`#64748b` 一类字面量**。两组常量故意不翻档：`--banner-*`/`--chip-*`、`--login-*` |
| 暗色改了没生效 | `element-plus/theme-chalk/dark/css-vars.css` 必须**早于** `@cornerstone/core/styles/index.css` 引入（同选择器靠后者取胜）；新增 `html.dark` 令牌要同时检查 `:root` 有没有对应项 |
| 入口看得见、点进去整页 403 | 读取码挂 `menu` 页面节点、写码挂 `button` 节点；导航项写 `menuCode` 而**不是 `alwaysVisible`**（后者等于绕过授权）。目录 `catalog` 节点永不挂码 |
| 改了权限 12 小时没生效 | 权限快照写进 JWT，要重登；管理接口侧要复用 `invalidateUserSessions` |
| 下拉显示"男"、报错说"可选值：male/female/unknown"，操作员不知道哪儿错 | 字典值中文名只来自 `item_name`（`dictStore.displayLabel`），**各端不许自建静态映射**；报错允许值写 `中文(代码)` |
| 页面上按钮名与后端权限串对不上、点了没反应 | `actions_json` 的 `action` 串必须与 `extraActions` 的键**一字不差**，没有任何校验能发现写错 |

### 3.6 文案

| 症状 | 处置 |
| --- | --- |
| 说明单独占一行，把表格顶下去 | **说明永远落在按钮行右端**；整段口径收进 `NoteHint` 问号浮层 |
| 说明写着"支持创建、编辑、启停" | 删。那是把按钮名字复述一遍。口径：**只写"不看就会用错"或"改完怎么生效"** |
| 页签/卡片标题旁边挂着条数 | 全站不显示条数：分页表看分页器总数，不分页的表都是刻意选定的小体量表 |
| 每张表上面都有一个页面大标题 | **一屏只有一张主表的页面不渲染 `.panel-title`**（横幅 `.banner-title` 已经是当前页名）；多表同屏才必须保留卡标题作区分 |

## 4. 四型页面与骨架

| 型 | 长相 | 标准处置 | 参照页 |
| --- | --- | --- | --- |
| **A 单主表** | 按钮行+筛选+一张表+分页 | `TableFillBox` 吃满，天然达标，不再讨论 | `ClassroomManagementView.vue` / `ListConfigManagementView.vue` |
| **B 表单/设置** | 一堆参数一次保存 | 标签与控件同行（CSS grid，不是 `el-form-item`）、分组横排；字段 >12 分两栏；保存固定在表单尾 | `TimeSlotConfigForm.vue` |
| **C 多件事堆叠** | 主档+关系表+风险+另一张关系表 | **按动作拆页互跳**，每页一件事 | `/time-slots` ↔ `/time-slot-list`（V82） |
| **D 只读汇总** | 工作台、总览、日课表、报表 | 允许滚，但**每个块自己封顶**（定高内滚 / 前 N 条 + "查看全部"），首屏那块要能做出下一步动作 | `/schedule-completeness`、`/system/permission-overview`、`/dashboard` |

C/D 边界判据：**这几个块有没有非看不可的关联**。改完主档马上要核对主讲 → 同页；只在给某学员打电话时才看家长联系人 → 拆走。**不要因为"它们是同一张表的数据"就同屏，那是后端视角。**

### 4.1 A 型骨架（服务端分页 + 排序，可直接改字段用）

```vue
<template>
  <section class="education-page">
    <!-- ① 按钮行：本页动作 → 圈圈 → 会跳走的 → 说明 -->
    <div class="table-toolbar">
      <el-button v-if="canManage" type="primary" @click="openDialog('create')">新增课程</el-button>
      <el-button :icon="Refresh" circle :loading="lookupLoading" @click="refreshAll" />
      <el-button @click="goClassTypes">班型档案</el-button>
      <div class="education-context-text">课程是班级主档与排课的前置档案</div>
    </div>

    <!-- ② 筛选行：只有点按钮才发请求 -->
    <FilterBar :loading="tableLoading" @query="reloadFirstPage" @reset="resetFilters">
      <el-input v-model="keyword" placeholder="编码/名称" clearable @keyup.enter="reloadFirstPage" />
      <el-select v-model="campusId" placeholder="校区" clearable filterable>…</el-select>
    </FilterBar>

    <!-- ③ 表格：TableFillBox 自量成 px -->
    <article class="panel-card education-panel">
      <TableFillBox v-slot="{ height }">
        <el-table ref="tableRef" :data="rows" :height="height" border row-key="id"
                  highlight-current-row v-loading="tableLoading"
                  :cell-class-name="sort.cellClass" @sort-change="sort.onSortChange">
          <el-table-column prop="courseCode" label="课程编码" width="150" fixed="left" sortable="custom" />
          <el-table-column prop="capacityLimit" label="容量" width="100" align="right" sortable="custom" />
          <el-table-column label="操作" width="150" fixed="right">
            <template #default="{ row }"><div class="table-actions">…</div></template>
          </el-table-column>
        </el-table>
      </TableFillBox>
      <el-pagination v-model:current-page="page" v-model:page-size="pageSize" class="panel-pagination"
                     :total="total" :page-sizes="[10,20,50]"
                     layout="total, sizes, prev, pager, next"
                     @current-change="loadRows" @size-change="reloadFirstPage" />
    </article>
  </section>
</template>

<script setup lang="ts">
const canManage = computed(() => auth.hasPermission('education:catalog:write'))
const sort = useTableSort({
  onSorted: () => { page.value = 1; void loadRows() },
  clearTableSort: () => tableRef.value?.clearSort(),
})
// sortParams() 无序时不传键，后端走自己的默认序
const result = await fetchCoursePage({ institutionId, keyword: trimToUndefined(keyword.value),
  page: page.value, pageSize: pageSize.value, ...sort.sortParams() })
</script>
```

一次性全量加载的小表（校区页两张卡、班级详情三张表、字典/数据源/列表配置页）**不发请求、本地排序**，写原生 `sortable` 即可，同样不要传 `height="100%"`。

### 4.2 B 型：标签与控件同行用 grid

```vue
<div class="ts-param-grid">
  <div class="ts-param-row ts-param-head">…表头…</div>
  <div v-for="g in groupDefs" class="ts-param-row">
    <span class="ts-param-cell ts-param-label">{{ g.label }}</span>
    <span class="ts-param-cell"><el-input-number v-model="form[g.key].count" size="small" controls-position="right" /></span>
  </div>
</div>
<style scoped>
.ts-param-row { display: grid; grid-template-columns: 88px repeat(6, minmax(0, 1fr)); align-items: center; gap: 2px 10px; }
.ts-param-grid { max-width: 880px; }
</style>
```

依赖未选上游时**整段收成一行动提示**；保存按钮在被编辑对象那一段的 `.table-toolbar` 里、紧贴内容上方（属"选中上游才出现的工作区动作行"，不参与按钮行排序规则）。

### 4.3 C 型：拆页互跳

```ts
// 跳之前把共用范围递过去，落地不许停在别的校区
educationScope.setCampus(campusId.value); void router.push('/time-slot-list')
```
两页顶上一颗互跳按钮（圈圈右边），共用模块级 store（`useEducationScopeStore`）而不是传 query 参数。**菜单节点要一起授权，只勾一边就是死链**（SQL 形态见 §6）。

### 4.4 D 型：封顶的两种写法

```ts
import { tableViewportHeight, TABLE_VIEWPORT_MAX_HEIGHT, TABLE_STACK_MAX_HEIGHT } from '@cornerstone/core/utils/table-view'
const AUX_TABLE_MAX_HEIGHT = tableViewportHeight(3)   // 辅助表按行数封顶内滚
```
- `TABLE_VIEWPORT_MAX_HEIGHT` = 6 行（254px）：**弹窗内/详情卡内的次要表**。
- `TABLE_STACK_MAX_HEIGHT` = 10 行（398px）：同屏叠放的长列表（日课表、点名名单）。
- 主列表**不用这两个常量**，用 `TableFillBox`。

### 量高探针（内置浏览器只有 568×553 可视面）

`evaluate_script` 注入 `.app-shell{width:1440px!important;height:900px!important} body{min-width:0!important}`，此后 `.app-content` ≈ **1286×729**。四条已知陷阱：

- **别用 `html{zoom}`**：媒体查询仍按未缩放的 `innerWidth` 判定，量出来的全是"降级版式"的虚高。代价是被 `≤1280/≤1400` 断点改过版式的块要额外 `!important` 把宽屏那档补回来（`.resource-grid` 两列、`.education-table-head{flex-direction:row}`、`.note-hint{margin-left:auto}`）。
- `ResizeObserver` 与 `requestAnimationFrame` 在这个 hidden 页**一次都不跑**：所以 `TableFillBox` 会停在首次同步量到的尺寸、`el-dialog` 取消后遮罩仍留在 DOM。**判据：读组件 `setupState` 或查库确认真实状态，别拿动画残留当功能坏了。**
- `getBoundingClientRect()` 与 `offsetHeight` 同坐标基准，别再叠 zoom。
- `evaluate_script` 有 **15 秒超时**，一次最多跳 2~3 个路由、每页等 1000~1200ms。取路由用 `document.querySelector('#app').__vue_app__.config.globalProperties.$router`，`router.push()` 保得住会话与探针样式。测完移除探针 style 节点。

## 8. 与配置化（低代码）的差距

`sys_list_config` 已能吃下的形态，手写页**不要再自己发明**：列宽/`fixed`/`align`/`sortable`/`renderer`、按钮 `action`/`label`/`position`/`buttonType`/`permission`、`page_json.description`、查询区（已换成 `FilterBar`）、`TableFillBox`（已内置）、分页。

下列仍是**手写页专属**，配置化引擎目前长不出这一维 —— 这些就是低代码要补的清单，也是本手册存在的理由：

1. **按钮行的"圈圈分隔位"规则**：`actions_json` 有 `position`，但没有"会跳走的按钮"这一档，`router.push` 型入口现在只能硬编码。
2. **`NoteHint` 长口径说明**与动态范围回显的区分。
3. **B 型表单页**：`dialog_json` 只覆盖弹窗表单，整页参数栅格（grid 同行、分栏、依赖未选上游时收起）没有配置形态。
4. **C 型拆页与互跳 + 菜单一起授权**：跨页关系不在任何配置里，靠迁移 SQL 的 `SELECT DISTINCT` 兜。
5. **D 型汇总页**：块级封顶（前 N 条 / 定高内滚）没有配置项。
6. **按需搜索下拉**：`sys_data_source` 能配候选来源，但"已选项名称本地缓存兜底""批量回查 `ids`"这两条仍在组件里写死。
7. **后端排序白名单**：列配了 `sortable:true` 但 Service 的 `Map<String,SFunction>` 没这个键 = 静默不能排序，两边没有任何机制保证同步。**配置化要落地，这一条必须先有校验**（报错文案已经把可选值列出来了，但没有启动期检查）。

动手前先看 §4 的型，再回这张表：**如果你在为一个"配置化本该覆盖"的形态写特例代码，那就是走错了路** —— 应该去补 `ConfigurableList`/配置键，而不是在页面里另起一份。
