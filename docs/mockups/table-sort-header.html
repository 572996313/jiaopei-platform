先说结论：竖线一开，「表头居中」和 Element Plus 现在的排序箭头是打架的。 EP 的箭头是个 24px 宽的占位块（.caret-wrapper， width:24px;height:14px），排在标题文字后面， 整块一起居中 —— 实测标题被推离列中心 12.5px（B 方案 7.5px，C/D 为 0）。 没有竖线时看不出来，有竖线 + 居中表头，两侧留白一眼就不对称。 第二件事：EP 把静置箭头刷成 --el-text-color-placeholder， 在我们表头底色上实测 1.98:1 —— 紧凑 + 竖线之下，"这列到底能不能点"完全没有信号。 所以箭头要一起定：摆位 + 静置色。下面那条粉色竖线就是每列的几何中心， 粉色数字是脚本量的偏差，不是估的。

为什么还要「排序列淡底」

表头居中 + 数字右对齐，标题和内容本来就错开半格；箭头再挂到右上角， 「这一列在排序」的信号就太弱了。整列淡底（含表头）把三者一次串起来， 也是你确认要竖线之后最划算的补偿。关掉它（顶部开关）你能看到差别。

为什么还要分页行那枚回显

箭头只有 9px，操作员点完常常不确定「现在到底按什么排」。 底部回显写成 排序：上课日期 · 升序 + 一个「取消」， 顺带解决「第三下点击=取消」这个没人知道的隐藏交互。

三态怎么定

升 → 降 → 无序，无序即不传 sortField，后端回自己的默认序 （课次是日期+开始时间）。同时只允许一列在排（已定）， 点另一列直接把状态挪过去，不做多列叠加。

3. 排序样式要定死的细节

哪些列有箭头

只有「该列只展示一个字段 ∩ 后端白名单有这个键」的列渲染箭头（这条已经落地： 14 个分页接口 + columns_json.sortable）。不可排序列什么都不加， 不要放灰色占位箭头——那会让人以为点不动是坏了。

静置箭头不许淡到看不见

EP 的 .sort-caret 默认色是 --el-text-color-placeholder， 在我们的表头底色上实测 1.98:1（夜晚档 3.16:1）。竖线一开，人只会以为这列不能点。 定值：静置 --text-secondary（5.13:1 / 7.13:1），激活 --accent， 靠颜色而不是靠透明度区分两态 —— 12.5px 的灰字压到 55% 就只有 2.7:1。 同一个道理也用在状态圆点上（见 v2 demo 的字典配色那条）。

hover 反馈

可排序表头 cursor:pointer（EP 的 th.is-sortable 自带）+ 文字变主色 + 淡底 --t-hover。不要做箭头淡→实的悬停动画： 紧凑档 14px 表头里那点位移看着抖。

键盘可达

EP 的 .caret-wrapper 自带 :focus-visible 外框； 换成自绘箭头后，焦点要落在整块 th 上（加 tabindex="0" + Enter/Space 触发），否则键盘用户只能靠 Tab 一路穿过。

窄列（width ≤ 70）

如「排序」「状态」。C 方案的角标不受影响；若选 B，箭头要压到 10px 且 margin-left:2px，否则「状态▲」会在 70px 里换行。

插槽列必须写 prop

用 #default 渲染的列（状态、操作、两行式）， sort-change 的 payload 取字段名靠的是 prop， 漏写就点了没反应。这条是纯踩坑记录，已写进 AGENTS.md。

排序和别的状态怎么打架

优先级：悬停 > 选中行 > 排序列淡底（本页就是这个顺序，可切开关验证）。 「重置」按钮一并清排序（clearTableSort）； destroy-on-close 的弹窗每次打开 resetSort()， 否则箭头消失但状态还留着。翻页保留排序。

不加排序的两类表

树表（菜单管理、功能权限总览）行序即层级；矩阵表（课次完成度的动态周列） 是透视结构。这两类连箭头都不渲染，也不进白名单交互。

后端不需要再动

这轮纯样式：sortField/sortOrder、白名单、主键 tiebreaker、 非白名单报错带可选值，上一轮已全部接完并冒烟过。

4. 选 C 的话，代码上改哪几处

  1. core 样式段 packages/core/src/styles/index.css： 把 .el-table .caret-wrapper 改成 position:absolute; top:3px; right:5px 并压掉它 24px 的占位宽； .sort-caret.ascending/.descending 的 border-*-color 从 --el-text-color-placeholder（实测 1.98:1）换成 --text-secondary，激活态用 --accent。 这一步覆盖所有表（含 ConfigurableList）， 因为 EP 的 DOM 结构不变，只挪样式。
  2. 排序列淡底：EP 没有「整列高亮」的原生开关，需要宿主表加 :cell-class-name 回调，按当前 sortField 命中的列索引返回 col-sorted。useTableSort 里补一个 cellClass({columnIndex})， 各表在 el-table 上挂一行即可（约 10 个文件，每文件 +1 行）。
  3. 底部回显：分页行左侧渲染 排序：{label} · {升序|降序} + 取消按钮； ConfigurableList 内置一份，手写表用同一个小组件。
  4. 口径同步：AGENTS.md「列表排序」那条要补三句——箭头摆位（角标绝对定位、不占文字宽度）、 三态含「无序=回落后端默认序」、优先级「悬停>选中>排序列淡底」。
