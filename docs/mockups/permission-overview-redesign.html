设计说明（给设计的口径，不进界面）

这一页要回答的三个问题

  • 这个权限码是什么（中文名、读取还是写入）；
  • 谁能用——两条来源要分开画：角色预设权限（sys_role.permission_codes CSV）与勾选菜单节点带出的码，撤销时两边都要撤；
  • 用了管什么——挂载节点（页面节点=进得来且读得到；按钮节点=一个写动作）+ 后端 @RequiresPermission 扫出的受控接口清单。

数据边界（不许出现在设计里的字段）

  • 接口只返回 17 个生效权限码及其接口清单、持有角色、挂载菜单节点、列表按钮配置，没有：调用量、覆盖率、健康分、最近调用时间、引擎/集群/CI/Git SHA 一类运行时信息，也没有权限申请流与审批人。
  • 页内不提供编辑：授权改动去「角色管理-分配菜单」「菜单管理」，此页只读，避免和那两个页面漂移。
  • 页面标题只在顶栏页签出现一次，不加页内大标题（全站口径）。
  • 按钮节点在菜单树里 visible=0，不占导航，只作权限码载体。

布局约束

  • 左栏宽 340px、右栏自适应、栅格间距 12px（与现有页面一致）；左栏 position:sticky 自量高，右栏接口列表内部滚动，不让整页拉长。
  • 统计卡四张按"有问题就变红"的规则：后两张正常应为 0（绿色），非 0 时是配置缺口，需要能一眼看出。
  • 窄栏（侧边栏收成图标）时本页不受影响，内容区从 12px 起算。

色彩语义（沿用 Element Plus）

  • 读取 绿 —— 页面节点上的读码，勾选即授予；写入 橙 —— 按钮节点上的写动作；单码读写 红 —— 读写共用一个 :manage 码的页（代价：无法配只读岗）；端访问 蓝 —— 小程序端入口码。
  • 接口行方法色：GET 绿 / POST 橙 / PUT 蓝 / DELETE 红，与全站表格一致。
