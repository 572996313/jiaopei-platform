## 2. 本地启动与联调说明

### 环境要求

- JDK: `21`，本次验真使用 `C:\Program Files\Java\jdk-21.0.11`。
- Maven: 项目使用 `backend/pom.xml` 中的 Spring Boot `3.5.0` 配置。
- MySQL: 默认连接 `127.0.0.1:3306/jiaopei_platform`。
- 数据库账号: 默认 `root` / `1234`，来自 `backend/app/src/main/resources/application.yml`。
- Flyway: 已启用，迁移目录为 `classpath:db/migration`。
- 鉴权: 先 `POST /api/auth/login` 获取 JWT,再携带 `Authorization: Bearer <accessToken>`;签名密钥 `cornerstone.auth.jwt.secret`(生产用环境变量 `AUTH_JWT_SECRET` 覆盖)。

### 启动命令

在 `backend` 目录执行：

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-21.0.11'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
mvn spring-boot:run -Dspring-boot.run.arguments=--server.port=18080
```
