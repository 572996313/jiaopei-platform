# 收费台账怎么用（大白话版）

一句话流程：

**先配「收什么、多少钱」→ 按班建台账 → 核对每个项目的应收参数 → 登记收款 → 点名后同步出勤 → 核对逐月发生 → 看结余 → 导出。**

菜单都在「**收费与财务**」下面：

- **收费项目与价目**：定义收什么费、按什么方式收、各维度什么价。
- **收费台账**：按学员建账、登记收款、同步出勤、看结余、导表。

> 先记住一句话：**应收是“该收多少”，实收是“实际收到多少”，合计发生是“已经消耗掉多少”，结余是“还能退多少”。**
> 结余 = 实收 − 合计发生。正数 = 可退，负数 = 发生超过实收（还该补收）。

---

## 一、先备齐这些基础数据（只做一次）

按顺序检查，缺哪样后面的数都会不对：

1. **学期**：必须维护**起止日期**。收费月表、收费出勤表导出、默认月数都靠它算；没有日期会直接报错。
2. **校区、班级、学员、名册**：台账按「学期 + 班级 + 学员」建，学员要在班级名册里（批量建账只读在读名册）。
3. **家长联系人**（可选但导出要用）：学员档案 → 行操作「联系人」，维护家长姓名、电话、**支付宝绑定电话**。
4. **课次点名能正常用**：出勤同步是从点名记录汇总的，不点名就同步不到天数。

---

## 二、第 1 步：维护收费项目

菜单：**收费与财务 → 收费项目与价目 → 新增收费项目**。

| 字段 | 怎么填 | 说明 |
| --- | --- | --- |
| 项目编码 | 可留空 | 留空自动生成 `FE-001` 这种编号；同一机构不能重复 |
| 项目名称 | 必填 | 如：保教费、伙食费、延时费 |
| 计费方式 | 必选 | **按月**：月标准 × 月份系数；**按天**：出勤天数 × 日标准 |
| 排序号 | 建议 10、20、30 | 越小越靠前，决定台账明细和导出表里的项目顺序 |
| 状态 | 启用/停用 | **只有启用项目**会在新建台账时自动建行；停用项目不影响已建台账 |
| 备注 | 可选 | |

建议先建齐源表里那三项：**保教费（按月）、伙食费（按天）、延时费（按月或按天，按实际口径）**。收费出勤表按「启用的项目」展开项目行；台账里已经用到的停用项目也会保留，避免历史金额凭空消失。

---

## 三、第 2 步：维护价目

菜单：**收费项目与价目 → 行操作「价目」→ 新增价目**。

四个维度（校区 / 班级 / 学期 / 学员）**留空 = 不限**。取价规则：

- 只考虑「启用」的价目；
- 价目的每个非空维度必须和目标一致；
- 按权重算总分：**学员 8 分、班级 4 分、校区 2 分、学期 1 分**，总分最高的那行胜出；
- **月标准和日标准各自独立回落**：学员级价目只配了月标准时，日标准继续往班级/校区/全局找。

价目弹窗里怎么看、怎么找：

- 表格把四个维度拆成独立列，留空显示灰色「不限」，一眼看出这条价目管到哪一级；
- 「级别」列按最高维度标成 学员级 / 班级级 / 校区级 / 学期级 / 全局，列表默认按权重从具体到宽泛排序；
- 顶部可按校区 / 班级 / 学期 / 学员 / 状态筛选，**「不限」的价目在任何筛选下都会出现**（它确实适用于所有人），右侧显示当前命中条数；
- 行操作「复制」可照着现有价目新建一条（维度可改），适合给另一个学员配覆盖价；同一组维度只能有一条价目，重复时会直接提示。


例：

- 全局价目：保教费 1500/月，伙食费 30/天；
- 再加一条「学员 = 温瑾瑜，保教费 1000/月」→ 温瑾瑜取 1000，其他学员取 1500；
- 如果只给某班配价，这个班优先于全局。

> 价目只是“建账时的取价来源”。**改价目不会回改已建好的台账**，已建台账的标准是快照；要改老台账，去台账编辑里改标准。

---

## 四、第 3 步：建台账

菜单：**收费台账**。两种方式：

### 方式 A：按班批量生成（推荐）

点「**生成台账**」→ 选学期 + 班级 → 开始生成。

- 只给该班**在读名册**里的学员建；
- 已有该学期台账的学员自动跳过，不会覆盖已录数据；
- 每个学员按当前**启用的收费项目**自动建行，并按价目表取标准。

### 方式 B：单个新增

点「**新增台账**」→ 选班级、学期、学员 → 保存。同样会自动建收费项目行。

> 建完后如果某个学员不该有某个项目（比如不收延时费），进「编辑」把那一行移除。已有收款或手工覆盖发生时不能移除。

### 建账时自动填的值

| 字段 | 默认怎么来 |
| --- | --- |
| 收费月数 | 学期各月默认系数之和。学期起始日不在 1 号时，起始月默认 **0.50**，其余月 **1.00**。例：8 月 15 日开学、上到 1 月底 → 0.5 + 1×5 = **5.50** |
| 月标准 | 按月项目按价目表取；没配价目就是 0.00 |
| 日标准 | 按天项目按价目表取；没配价目就是 0.00 |
| 上期结余 | 0.00（正数 = 上期预收，会冲减应收；负数 = 上期欠费，会增加应收） |
| 其他抵扣 | 0.00 |
| 应收 | 不落库，按下面公式现算 |

---

## 五、第 4 步：核对台账明细（决定“应收”）

**收费台账 → 行操作「编辑」**。这里能改每个项目的：

- 收费月数
- 月标准、日标准（**留空 = 按价目表重新取价；显式填 0 = 免费**）
- 上期结余、其他抵扣
- 备注

应收公式（每个项目各自算，再汇总）：

```
项目应收 = 收费月数 × 月标准 − 上期结余 − 其他抵扣
```

注意：

- **上期结余、其他抵扣是“每个项目分开的”**，要填在对应的项目行上；
- 按天项目通常月标准是 0，所以它的“应收”一般也是 0；伙食费靠“发生额”消耗，不预先计入应收；
- 台账头的应收 = 所有项目应收相加。

---

## 六、第 5 步：登记收款

**收费台账 → 行操作「收款」→ 填写并提交**。

| 字段 | 说明 |
| --- | --- |
| 收费项目 | 这笔钱算到哪个项目头上，**必须选对**，否则该项目的实收/未收费/结余会偏 |
| 收款金额 | 正数 = 正常收款；**负数 = 冲正/退回** |
| 收款日期 | 必填 |
| 收款方式 | 现金/微信/支付宝/银行转账/其他（字典） |
| 归属账期 | 可选，只作备注归属；**不参与发生额计算** |
| 凭证号 / 银行流水号 | 可选 |
| 收款单号 | 留空自动生成 `SK-日期-序号` |
| 备注 | 如“按月收” |

同一个项目可以分多笔登记。实收 = 该项目所有收款流水之和（负数会抵减）。

```
项目实收 = Σ 该项目全部收款金额
项目未收费 = 项目应收 − 项目实收
```

**未收费为负不是错**，表示预收/多收。

---

## 七、第 6 步：点名 → 同步出勤

出勤从点名记录来。先在「执行与课表 / 课表与点名」或「点名总览」里把课上完、点完名，然后：

**收费台账 → 行操作「逐月/出勤」→ 从考勤同步**。

汇总口径：

```
考勤汇总天数 = 该班该学员当月「出勤 present + 迟到 late」的不同日期数
```

- 请假、缺勤不计；
- 同一天上了两节课，只算一天；
- 未点名的月份会得到 0 天。

同步时：

- 没手工改过的月份，生效出勤天数 = 考勤汇总天数；
- 手工改过的月份，**保留手工值**，只刷新“考勤汇总天数”做对照。

> **这一步千万别省。** 按月项目也要求出勤天数 > 0 才有发生额；不点名的月份发生额是 0，结余会看起来像“全都能退”。

如果某个月考勤记错了，可以在表格里直接改「生效出勤天数」，然后统一保存；想恢复自动值，点该行「**撤销覆盖**」。

---

## 八、第 7 步：核对/调整逐月发生额

**收费台账 → 行操作「逐月/出勤」**，下半部分是逐月发生额。每个项目、每个账期一行。

系统自动算：

```
按月项目自动金额 = 出勤天数 > 0 ? 月标准 × 月份系数 : 0
按天项目自动金额 = 出勤天数 × 日标准
```

- **月份系数**：默认学期起始月 0.50（仅当起始日不是 1 号），其余 1.00；每个项目每个月可以单独调；
- **生效发生额**：没手工覆盖时 = 自动金额；
- 手工改过生效发生额后，该行标记「已覆盖」，之后**重算不会改它**；
- 想恢复自动值，点该行「**撤销覆盖**」；想一次性全恢复，点工具栏「**全部恢复自动**」。

### 批量保存

直接改单元格（改了会整行变色），改完点右下角：

**「保存全部修改（N）」**

一次提交所有改过的出勤行和发生额行。部分失败时，失败的行会保留在表格里并列出原因，不会全部丢。

> 工具栏的「按当前出勤重算」会刷新**自动金额**和**未覆盖行**的生效值，手工覆盖行不动。执行前如果有未保存的修改，会提示你先确认。

---

## 九、第 8 步：看结果

台账列表每行的含义：

| 列 | 怎么算 |
| --- | --- |
| **应收** | Σ 各项目应收 |
| **实收** | Σ 各项目收款流水 |
| **未收费** | 应收 − 实收（负数 = 预收/多收） |
| **合计发生** | Σ 各项目各月「生效发生额」 |
| **结余（可退）** | 实收 − 合计发生（正数 = 可退，负数 = 发生超过实收） |
| **状态** | 在收 / 已结清，**手工标记**，不参与计算，也不拦截编辑 |
| **备注** | 台账头备注，如“国兴QQ班转入”“按月收” |

这些值**都不落库**，每次打开都从收款和逐月发生表现算，所以删一笔收款、改一次发生额，结余会立刻跟着变。

---

## 十、第 9 步：导出

### 收费出勤表（3 个 sheet）

**收费台账 → 先选学期 + 班级 → 导出收费出勤表**。生成一个工作簿，拆成三张表，每张顶部都有标题和「班级 / 单位：元」：

- **家长情况**：学号、学员姓名、家长关系、家长姓名、联系电话、支付宝绑定电话、主联系人。每个家长一行，同一学员的学号/姓名纵向合并；主联系人的支付宝电话就在标记「是」的那一行。
- **收费内容**：学号、学员姓名、收费内容、收费月数、收费标准、上期结余、其他抵扣、应收金额、实际收款、未收费、结余、备注。每个项目一行，每个学员一行小计，表尾总计。收费标准取月标准（按天项目的应收也按这一列算）；备注在学员块内合并。
- **出勤明细**：学号、学员姓名、项目、日标准、各月、合计发生。每个学员第一行固定「出勤天数」，下面按项目列逐月发生额，最后一行小计；表尾先按项目汇总，再给总计。

> 结余和备注都放在「收费内容」里，出勤明细只看到消耗（发生额）。三张表先不合并成一张，财务需要时线下复制到一个 sheet；合并版后续再做。

> 必须先选学期和班级：按“同一班同一学期”成表。学期没维护起止日期会报错。

### 一维明细

**导出明细**：一个工作簿两张 sheet。

- **台账明细**：每学员每项目一行。列：校区、学期、班级、学号、学员姓名、收费项目、计费方式、收费月数、月标准、日标准、上期结余、其他抵扣、应收金额、实际收款、未收费、合计发生、结余、台账状态、备注。
- **逐月发生**：每学员每项目每月一行。列：校区、学期、班级、学号、学员姓名、收费项目、账期、月数系数、出勤天数、自动金额、最终发生额、手工覆盖、备注。

## 十二、公式总表

```
项目应收      = 收费月数 × 月标准 − 上期结余 − 其他抵扣
项目实收      = Σ 该项目收款流水（负数冲正）
项目未收费    = 项目应收 − 项目实收          （负数 = 预收/多收）
项目合计发生  = Σ 该项目各月生效发生额
项目结余      = 项目实收 − 项目合计发生

台账应收      = Σ 项目应收
台账实收      = Σ 项目实收
台账未收费    = 台账应收 − 台账实收
台账合计发生  = Σ 项目合计发生
台账结余      = 台账实收 − 台账合计发生      （正数 = 可退）

默认月份系数  = 学期起始月且起始日 > 1 ? 0.50 : 1.00
默认收费月数  = Σ 学期各月默认系数
按月自动金额  = 出勤天数 > 0 ? 月标准 × 月份系数 : 0
按天自动金额  = 出勤天数 × 日标准
生效发生额    = 手工覆盖 ? 覆盖值 : 自动金额
考勤汇总天数  = 当月 present/late 的不同日期数
```

金额算到 4 位小数、单价（月标准/日标准）保留 6 位、天数/月数/系数保留 4 位，全程四舍五入（HALF_UP）；页面与导出按最多 4/6 位小数展示，末尾多余的 0 不显示。

## 十三、常见坑

1. **学期没填起止日期**：建不了逐月发生额，矩阵也导不出。先去「校区与学期」补齐。
2. **没配价目就建账**：标准是 0，应收也是 0。先配价目再建账，或建完后到台账编辑里补标准。
3. **价目改了，老台账没变**：正常。价目只影响新建台账；老台账的标准是快照。
4. **忘记录考勤就同步**：所有月份出勤 0 → 按月项目发生额 0 → 结余看起来像“全退”。先点名再同步，或手工补出勤。
5. **改了月份系数，但生效发生额没变**：生效发生额以那一格为准；想按新系数生效，把「生效发生额」也改成对应金额（改过并保存的行会变成手工覆盖，之后重算不会自动改）。
6. **手工覆盖后重算不动**：这是设计。要恢复自动值，点行内「撤销覆盖」或「全部恢复自动」。
7. **收款项选错项目**：台账总实收不变，但该项目的未收费/结余会偏；删掉重录。
8. **未收费是负数**：不是错误，表示预收或多收。
9. **台账有收款不能删**：先删收款或改状态；收费项目行有收款/手工覆盖时也不能移除。
10. **批量建账漏人**：批量只读“在读”名册；插班生没在名册里就用「新增台账」补。

## 十四、日常维护节奏

- **每次收到钱**：当天在对应台账登记收款，选对项目。
- **每天/每节课**：正常点名；点名是出勤的唯一来源。
- **每月月底**：逐月/出勤 → 从考勤同步 → 核对异常月份 → 必要时手工改出勤或发生额。
- **学期中随时**：看台账列表的应收/实收/未收费/结余，有疑问点进「编辑」查项目参数。
- **期末**：先选学期 + 班级导出收费出勤表交财务；需要逐项核对时再导一维明细。
